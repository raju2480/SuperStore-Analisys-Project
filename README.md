# Superstore Sales Analysis using Python

## 📌 Project Overview

This project presents a comprehensive **Exploratory Data Analysis (EDA)** of the Superstore dataset using Python in Jupyter Notebook. The primary objective is to extract meaningful business insights from historical sales data and support data-driven decision-making. The analysis focuses on understanding sales performance, profitability, customer behavior, regional trends, product performance, and the impact of discounts on profit. By using data visualization and statistical analysis, the project helps identify opportunities to improve business performance and operational efficiency.

## 🎯 Objectives

* Perform data cleaning and preprocessing.
* Explore the structure and quality of the dataset.
* Analyze sales, profit, quantity, and discounts.
* Identify top-performing and loss-making products.
* Analyze customer segments and regional performance.
* Visualize key business trends using charts and graphs.
* Generate actionable business insights for decision-making.

## 🚀 How to Run

1. Clone this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Open the Jupyter Notebook.
4. Place the `SampleSuperstore.csv` dataset in the project folder.
5. Run all notebook cells sequentially.
